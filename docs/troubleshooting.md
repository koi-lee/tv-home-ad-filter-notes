# 失败实验与经验

| 方法 | 当时结果 | 处理 |
| --- | --- | --- |
| 公共过滤DNS | 广告照播 | 进入实际请求定位 |
| Rethink静态IP拒绝 | 三个精确IP仍有广告 | 撤回，域名存在地址变化 |
| 仅拦广告媒体 | 广告没播但约35秒加载 | 分析内部失败重试 |
| HTTP410/204 | 多次BadResponse，仍约35至37秒 | 撤回临时服务 |
| 0.08秒素材响应 | 一次约21秒，另一次出现113秒倒计时 | 未纳入最终方案 |
| 拦UPS共用接口 | 超过60秒并报网络错误 | 恢复，不能当独立广告入口 |
| 拦vali-ugc/vali-g1素材域名 | 中插黑屏超过一分钟，暂停仍可能有图片 | 撤回这组候选 |
| 仅开启后台权限 | 冷启动过滤器未恢复 | 增加启动流程并真机验收 |
| Launch on Boot | 能启动过滤器，需返回首页 | 后续用助手自动回原首页 |

系统日志曾确认一次广告下载OpenTimeout约40000毫秒，支持等待来自重试的判断。其他节目是否同一路径，需要重新采集。

规则命中、应用安装成功、VPN已连接均不能单独证明体验通过。曾误入其他节目、从历史续播、无参数拉起详情导致播放串为空，均需从有效样本排除。

## 新故障定位

先记节目、集数、进度和片头/中插/暂停类型。检查过滤器进程及VPN，再采最短必要窗口。按广告触发时间与Host匹配提出一条候选，单变量测试，异常即恢复原配置。

ADB连接失败时重新核对电视亮屏、联网、实时IP和本地授权。屏保可能改变前台，截图确认新状态后再操作。不要让家人在没有变更时反复重测。
