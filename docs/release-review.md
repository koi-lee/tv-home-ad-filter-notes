验收时请重点检查以下内容。

- README对外主张是否符合个人实测经历。
- 文档中三域名及四属性是否仅限所述版本与样本。
- 是否愿意下一阶段公开启动助手源码。当前包仅含设计，没有可安装助手或完整一键部署能力。
- 新仓库名称、公开范围和许可证需在正式发布前确定。
- 未来纳入代码时重新做隐私检查、第三方许可核对、可复现构建和实际回退验证。

本次核验包括相对链接、示例配置与原文件一致、文件类型及常见敏感标识扫描。没有新一轮电视、安装、构建或播放验收。
