# 验证范围

证据来源为原项目当前进度、助手README、六分类测试记录及用户反馈。原始日志留本地，本文仅整理结果。

| 项目 | 已有记录 | 限制 |
| --- | --- | --- |
| 片头 | 人民的名义、谷雨指定样本，用户确认无视频广告及倒计时 | 全集与所有时段未穷尽 |
| 加载 | 用户测得约14至18秒；此前约35秒 | 无统计分布，不能保证每次相同 |
| 中插 | 人民的名义第2集约15分钟曾复现；后续规则及保护参数有指定窗口验证 | 未验证所有广告机会 |
| 自启 | 助手0.3两次系统重启及真实拔电恢复记录 | 固件/插件升级后须重测 |
| 电脑离线 | 用户关闭Mac Wi-Fi后播放正常 | 持续采集仍依赖电脑在线 |
| 暂停 | 纪录片暂停20秒抽样未见广告 | 未证明当次必有广告机会 |

## 下一位测试者如何验收

从原首页选免费内容，记录节目、集数、播放器与点击时间。观察首帧、至少一分钟连续播放、暂停恢复、换集，以及实际中插点。再独立完成重启和断电流程。每轮分别记录画面、倒计时、黑屏、日志与正片进度。没有广告事件仅是辅助证据；没有对照的无广告样本不能直接算规则命中成功。
